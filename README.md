## 演示内容（与验收标准对应）

**① 授权字段强制校验**（验收第 2 条）
`PatternLibrary.ingest()` —— 缺 `origin/license_scope/rights_holder/
expires_at` 任一字段**拒绝入库**并指明缺哪些；完整则入库（正反例均含）。

**② 可制造性评估助手**（验收第 3 条）
`ManufacturabilityChecker` —— 规则表显式可维护（非程序员可改），
10 个概念输入（含 3 个不可制造反例）评估 **10/10 与规则预期一致**，
失败逐条给出具体原因与调整建议，判据可复跑。

**③ C2M 订单链路**（验收第 4 条）
`C2MOrder` —— `created → craft_order → dispatched → qc_passed →
shipped → settled` 全链路；**退款**（三态内可退）与**争议**路径均有
用例；台账逐事件留痕（状态+金额）可追溯；终态再流转被拒。

## 自动化测试（验收第 8 条）

`run_tests.py` 即单测本体：授权校验 2 项、可制造性 2 项、订单链路 5 项、
